# Credit Assistant: AI-Powered Financial Health Advisor 🇮🇳

An end-to-end platform built for Indian banking users to manage, monitor, and improve their credit standing (CIBIL score, DTI, credit utilization) with Google Gemini AI advice.

## 🚀 Local Setup Instructions

### 1. Backend Setup
```bash
cd backend
python -m venv venv
# On Windows: venv\Scripts\activate
# On Unix: source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env and enter your GEMINI_API_KEY
python seed.py
uvicorn app.main:app --reload --port 8000
